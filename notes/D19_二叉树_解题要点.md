## 核心方法（来自 binary-tree-basics）

### 1. 遍历三兄弟

| 方式 | 顺序 | 栈/队列 | 典型用途 |
|---|---|---|---|
| 前序 preorder | 根 → 左 → 右 | 栈 | 复制树、序列化、前缀表达式 |
| 中序 inorder | 左 → 根 → 右 | 栈 | **BST 天然有序**、求第 k 小 |
| 后序 postorder | 左 → 右 → 根 | 栈 | 释放树、**树形 DP**、求高度 |

**关键口诀**：前序「根左右」= 头结点；中序「左根右」= 中间；后序「左右根」= 尾结点。

### 2. 递归三要素（面试必答）

1. **定义**：函数做什么（返回值代表什么）
2. **终止条件**：什么情况直接返回
3. **递归关系**：子问题怎么合并

### 3. 递归 ↔ 迭代

- 递归转迭代：显式 stack（注意**先压右子树**才能得到正确的左先顺序）
- 迭代转递归：按三要素反推
- **统一遍历框架**（万金油）：

```
while stack or q:
    while stack: push(stack.pop())
    ...
    node.left -> stack, node.right -> q
```

### 4. 高频题型清单

| 题型 | 关键技巧 |
|---|---|
| 最大深度 | 后序：max(左, 右) + 1 |
| 层序遍历 | BFS 队列，每轮先记 `len(q)` 定层 |
| 翻转二叉树 | 前序/后序，交换左右子树 |
| 平衡二叉树 | 后序求高度，差值 >1 即不平衡 |
| 验证 BST | **中序遍历必须严格递增**（陷阱：用全局变量比较会漏掉跨子树污染） |
| 最近公共祖先 | 后序：左右都非空 → 当前；否则返回非空的那个 |

### 5. 三个高频陷阱

1. **验证 BST 用全局 prev**：前一个节点可能来自**不同的子树**，会导致误判。正确做法是把 prev 作为参数传下去（限定在当前调用链内），或用上下界（`min < node.val < max`）传递法。
2. **层序遍历忘记记录当前层长度**：`while q: n = len(q)` 要在**每轮开头**取。
3. **迭代遍历压栈顺序**：先压右，才能先弹出左。
